# 实现水玻璃 react组件

基于svg 滤镜实现react水玻璃组件，类似ios的效果

## 用法

```jsx
<LiquidGlass />

<LiquidGlass>{children}</LiquidGlass>
```

## 要求
- 可发布到npm，公共使用，检查一下组件名称，不要使用已有的名称
- 代码简单
- 使用tsdown作为脚手架
- 需要测试文件
- 生成 demo html
    - 可以调节参数查看效果
    - 有几个推荐的默认效果
- 参数
    - 支持单一的强度参数，由强度计算出
    - 也支持更专业的参数，如果设置
- readme
    - 只写简介和用法
    - 中英文，默认中文


- 要可以用在普通元素上，而不仅仅是悬浮的元素
- 只设置强度，中间区域完全透明，能不能也带一点点模糊
- 组件叫 liquidrop  好吗？ 有没有更准确更好的名称
